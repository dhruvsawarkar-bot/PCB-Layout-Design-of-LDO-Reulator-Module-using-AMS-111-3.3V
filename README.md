# PCB-Layout-Design-of-LDO-Reulator-Module-using-AMS-111-3.3V
PCB layout design of an LDO Regulator Module using the AMS1117-3.3V regulator. The project converts a 12V DC input to a stable 3.3V output, with proper component placement, routing, decoupling capacitors, and a compact PCB layout designed using KiCad.
